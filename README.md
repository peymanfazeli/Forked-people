# Forked People

A narrative decision game where you live through the lives of historical figures — without knowing who you are until the final reveal.

## How It Works

- You enter the life of a famous historical person
- At each turning point, you make a YES/NO decision
- The story continues based on your choice
- At the end, the identity is revealed
- Your decisions are compared with the real historical path

## Play

```bash
npm install
npm run dev
```

## Built With

- React 19
- TypeScript
- Vite
- Rive (animations)
